# Contorni selezionati della Regular

Questi 106 SVG e il manifesto sono gli input della Regular 1.000.
Le diciture alpha/trial nel manifesto e nei titoli SVG
sono metadata del checkpoint originale, preservati per la tracciabilità.
Le copie selezionate in questo archivio sono OFL 1.1, secondo
OFL.txt e docs/LICENSES.md; il font compilato finale è la 1.000.

Sette minuscole normalizzate mantengono riferimenti a lettere
revisionate. Le altre forme sono completamenti contemporanei o
elementi tecnici. Le sette copie SVG nella cartella V3 servono
al controllo della linea di derivazione; nessun pilota binario
o altro materiale delle proposte è incluso.

SVG 1000×1000, baseline y=800, contorni chiusi pieni senza stroke.
Manifesto e contorni vengono convalidati dal codice originale.
